🛍️ E-Commerce Mini - Django Online Store

A fully functional e-commerce web application built with Django, featuring product management, shopping cart, user authentication, order processing, and responsive design.

 ✨ Features

 👤 User Features
- User registration, login, and logout
- Browse products by categories
- Search products by name or description
- Add/remove products to shopping cart
- Update cart quantities
- View order history
- Product reviews and ratings
- Responsive design for mobile & tablet

 👑 Admin Features
- Complete CRUD operations for products
- Category management
- Order management
- User management
- Inventory control
- Discount and sale management

 🛒 Shopping Features
- Dynamic product listing with filters
- Price filtering (min/max)
- Sort by price (low to high / high to low)
- Sale badges for discounted items
- Featured products section
- Related products recommendations
